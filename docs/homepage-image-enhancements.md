# Homepage photo enhancements

Created with the built-in ImageGen tool in edit mode. Original files retained. AI enhancement reconstructs fine details; these are not recovered original-resolution photographs.

Outputs in `public/images/homepage-enhanced/`:
- `teaching-img.webp`
- `beyond-surgery-1st.webp`

Each uses the identically named original under `public/images/` as its edit target. Converted generated PNGs to WebP at quality 95 without resizing.

## Exact prompt (each image)

Use case: identity-preserve. Edit target: the supplied original photograph. Asset: website photograph. Conservatively enhance resolution and reduce blur/compression artifacts, producing a clear natural photograph at about 1800 pixels wide with original aspect ratio. Preserve EXACT composition, crop, every person's identity, facial features, age, expression, pose, clothing, hands, objects, background, lighting and colors. Do not redesign or beautify faces. Keep existing text and diagrams unchanged, do not invent legible text. Recover modest natural texture without plastic skin, halos, excessive sharpening or stylization. Change only image clarity; no added or removed people or objects.
